# Sarah Pradhan — Portfolio

Static portfolio site for Sarah Pradhan, built with plain HTML, CSS, and JavaScript. It is ready for GitHub Pages.

## Run locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Publish on GitHub Pages

1. Create a new public repository on GitHub. A repository named `your-username.github.io` gives you the cleanest personal-site URL.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then click **Save**.
5. Wait for the deployment to finish. Your site will be available at `https://your-username.github.io/` (or at the project-repository URL if you chose a different repository name).

## Personalize before publishing

- Replace the three project descriptions with links to your actual repositories or papers.
- Add a PDF resume if you want a download button.
- Replace the Google Fonts import if you want the site to work without any external font request.
- Update the footer year and current role when your profile changes.
